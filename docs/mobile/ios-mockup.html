Design study · Javad Logger

The logger, reduced to what an iPhone can actually do

The desktop application opens a COM port, sweeps nine baud rates until a GREIS checksum verifies, and writes CSV to a folder you choose. An iPhone can do none of those three things — so this build does not pretend to. Everything with no iOS route has been taken out rather than drawn as a control that would never work.

What is left is the part that was never about the cable: a receiver reached over TCP on its own Wi-Fi access point, the same five GREIS messages at the same twelve periods, the same three commands on the wire, and one CSV row per position epoch.

The connection, from JAVAD's own iOS manual

Address
192.168.0.1 — the receiver's own address in adhoc mode, and its gateway.
Port
8002 — set by set,/par/net/tcp/port,8002. Ports 8010–8014 are a different job: RTN correction streams, not this.
Password
set,/par/net/passwd,"1234" — guards TCP and FTP together.
Access point
set,/par/net/wlan/mode,adhoc, an SSID via /par/net/wlan/ap/ssid (TRIUMPH2_008 in the manual), DHCP server on, client off — then set,reset,yes, because Wi-Fi changes do not take effect until the receiver restarts.

Taken out, and what replaced it

  • USB and Bluetooth serial to a COM port TCP to the receiver's Wi-Fi access point. iOS will not open a Bluetooth SPP link without MFi certification, and has no serial API at all. Triumph-1, 1M and 2 all raise an adhoc AP; the phone joins it and opens a socket.
  • Sweeping 115200, 460800, 230400 … until something answers A host and a port. There is no baud rate on a socket, and the address is not a guess — it is a documented default the receiver was configured with.
  • Enumerating COM ports and naming each one One probe against one address. The proof did not change: a verified rotate-and-XOR checksum, or a reply to print,/par/rcv/model:on from a link that stayed quiet. Only the transport underneath it did.
  • Choosing a folder for the CSV The app's own container, visible in Files. iOS has no free filesystem. Files land under On My iPhone › Javad Logger, and leave through the share sheet.
  • Recording while the window is behind another one Foreground only, with the screen kept awake. iOS suspends a backgrounded app and closes its sockets. The app says so and holds the idle timer instead of failing quietly.

Two iOS facts the design has to admit

Local Network permission. The first socket to a device on the same Wi-Fi triggers a system prompt. Denied once, it can only be re-granted in Settings — so the app asks at the moment the user taps Connect, when the reason is obvious, rather than at launch.

The receiver's AP has no internet. iOS says so on joining, will quietly prefer cellular for anything it can, and may offer to leave the network. The Link tab reports which network the socket is actually on.

Numbers on screen are a plausible RTK Fixed session on a bench, not live data. The five messages, their column counts, the twelve periods and the nine solType labels come from greis/catalog.py and greis/epoch.py unchanged.

Address

TRIUMPH-2 — [PG] checksum verified

A verified checksum is proof rather than a guess: the header, the body length and every byte between them have to be right for it to come out. A link that stays quiet through the listening window is asked print,/par/rcv/model:on instead — a receiver answers, an idle socket does not.

Receiver

Model TRIUMPH-2
Leave the receiver unchanged PPP, corrections, base/rover mode and every /par/net setting are left alone. Only which messages are enabled on this connection changes.

Log

Every ticked message adds its own columns to the file, at its own period.

Messages

Position cannot be switched off: it is the message that closes an epoch, so without it there is no moment at which a row becomes complete. A slower message leaves no holes — its last value is carried forward onto every row until the next one arrives.
